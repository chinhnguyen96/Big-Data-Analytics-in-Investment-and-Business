# Big Data Analytics in Investment and Business

## 📌 Overview

This repository contains academic projects developed for the course **Big Data Analytics in Investment and Business**.

The projects focus on applying Big Data technologies and analytical methods to real-world business and investment problems, transforming raw data into meaningful insights that support data-driven decision-making.

### 🎯 Key Objectives

- Process and analyze large-scale datasets using **PySpark**.
- Perform data cleaning, transformation, integration, and exploratory data analysis (EDA).
- Identify business trends, customer behavior, and investment patterns.
- Develop interactive dashboards using **Power BI**.
- Build data analytics applications using **Streamlit**.
- Generate actionable business insights and recommendations.

### 🛠️ Technologies

**Python | PySpark | Spark SQL | Pandas | Power BI | Streamlit | Jupyter Notebook**
